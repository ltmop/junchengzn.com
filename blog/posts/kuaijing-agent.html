跨境 Agent 落地：一个职能，一个 Agent

3 个人的创业团队，要做虾皮越南站的选品、定价、上架、广告、客服、物流、财务……人手永远不够。我们的解法不是招人，是把公司拆成 20 个 AI 角色。

为什么是「一个职能，一个 Agent」

早期我们也试过让一个 AI 什么都干，结果就是什么都干不精：写 Listing 的时候忘了定价规则，回客服的时候忘了物流政策。后来定了一条原则：一个职能对应一个 Agent，每个 Agent 只背一套知识、一个目标、一份检查清单。

就像真实公司按部门分工一样，我们的 AI 角色也按部门划分：

  • 运营部（7 个 AI 角色）：选品 → 定价 → 上架 → 广告 → 客服 → 数据 → 内容，一条链路拆到底；
  • 物流部（7 个 AI 角色）：物流方案 → 仓储 → 发货 → 包装 → 报关 → 退货 → 总监督；
  • 财务部（3 个 AI 角色）：P&L 报表、成本核算、汇率风控；
  • 供应链（3 个 AI 角色）：调拨、供应商管理、质检。

人机分工：AI 干活，人做决策

这套架构的核心不是"AI 替代人"，而是把人从重复劳动里解放出来。我们的分工原则很明确：

  • AI 负责：数据处理、报表生成、翻译、文案、Listing 生成、广告出价调整（ROI 驱动）、库存监控与低预警、补货建议、客服第一响应、竞品价格与 Listing 监控、汇率盯盘、成本核算。
  • 人负责：战略方向、异常决策、供应商谈判、客户关系、资金安全、内容创意方向、AI 角色绩效评估。

审批红线：AI 不可越过

AI 可以建议，但下面这些动作必须有人拍板，Agent 无权直接执行：

  • 新品上架（选品经理 → 运营负责人审批）；
  • 价格调整超过 20%（定价分析师 → 运营负责人审批）；
  • 广告预算变更（广告投放师 → 创始人审批）；
  • 大额退款（客服专员 → 运营负责人审批）；
  • 供应商切换（供应商管理 → 创始人审批）；
  • API 费用超预算（财务主管 → 创始人审批）。

每天的汇报链路

每晚 22:00，各 AI 角色汇报当日工作 → 部门总监（AI）汇总 → 数据分析师（AI）出日报 → 创始人审核后同步到团队群。三个人每天花十分钟看完日报，就知道全盘在发生什么。

Agent 帮周总保持清醒——这是我们在战略手册里写下的一句话。AI 不是来抢活的，是来当那 20 个不知疲倦的员工。

这套架构我们现在每天都在用，跑的就是虾皮越南站的真实业务。它不是一个概念验证，是一份每天都在产生数据的组织方案。
