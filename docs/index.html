🔌 三种接入方式

① 命令行 CLI

一台服务器部署云端，各电脑 node inv.mjs login 绑定，数据自动共享。

② HTTP Agent 接口

局域网 /api/invoke + 访问令牌，支持查询与常用操作，供其他 Agent 接入。

③ 开发 Skill

把本技能包放入 ~/.dsh/.agent-presets 或技能目录，即可让 AI 直接开发/改造系统。

💡 访问令牌：桌面端「设置 → 手机看店」查看/重置；云端注册账号后多台电脑数据互通（AES-256-GCM 加密）。
