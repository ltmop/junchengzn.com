核心功能

数据录入与查看

Web 界面即开即用，录一笔、改一处都实时反映到成表。

外部 Agent / 协作者走只读接口查数据，读写权限分离。

CLI 直连

人机协同

桌面 + Web 双入口

Electron 桌面壳网页打开，或浏览器直开，怎么方便怎么来。

常见问题

几个关键问题。

和进销存、驾驶舱有什么关系？

共用同一份经营数据：进销存产生数据，经营数据台负责集中管理，驾驶舱负责汇总展示。一套数据，三个视角。

外部 Agent 怎么接入？

通过 HTTP 只读网关查询，或走 CLI 直连；只读凭据和录入凭据分离，权限干净。

数据安全吗？

凭据本机保存（已 gitignore），只读与录入分权；云同步按需开启，默认本地。
