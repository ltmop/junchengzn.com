核心功能

同一份经营数据，人看、AI 也能查。

数据录入与查看

Web 界面即开即用，录一笔、改一处都实时反映到成表。

HTTP 网关只读查询

外部 Agent / 协作者走只读接口查数据，读写权限分离。

CLI 直连

命令行查询、脚本对接、批量操作，方便自动化。

Excel / CSV 导入

老账、盘点表一键导入，不用手工录。

人机协同

给 AI 留只读口，给人在 Web 界面录数，两边共用一份库。

桌面 + Web 双入口

Electron 桌面壳网页打开，或浏览器直开，怎么方便怎么来。

使用场景

经营数据怎么进、怎么出、怎么被 AI 用。

经营数据集中录入

进销存、销售、费用都录到一处，Web 界面即开即用。

报表与导出

按需查询、Excel / CSV 一键导出，复盘或报账都用它。

外部 Agent 只读接入

给 AI 开只读网关，AI 查数、人录数，两边共用一份库。

与进销存、驾驶舱同源

一套数据三个视角：进销存产生数据、数据台管理、驾驶舱展示。

我们自己的使用案例

让 Agent 和我们用同一份真实数据。

人机共用一个库

我们的 AI（CEO 驾驶舱、日常经营问答）都通过它读经营数据、写台账；人则在 Web 界面录数、看表。只读凭据和录入凭据分开，权限干净，谁也不会误改对方的数据。

  • 外部 Agent / 协作者走 HTTP 只读网关查询，不碰写入
  • 老账、盘点表用 Excel / CSV 批量导入，不用手工敲
  • 人机协同：你录数据，让 AI 去分析，两边始终一致

常见问题

几个关键问题。

和进销存、驾驶舱有什么关系？

共用同一份经营数据：进销存产生数据，经营数据台负责集中管理，驾驶舱负责汇总展示。一套数据，三个视角。

外部 Agent 怎么接入？

通过 HTTP 只读网关查询，或走 CLI 直连；只读凭据和录入凭据分离，权限干净。

数据安全吗？

凭据本机保存（已 gitignore），只读与录入分权；云同步按需开启，默认本地。
